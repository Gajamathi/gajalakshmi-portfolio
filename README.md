## About the Portfolio

This portfolio presents selected documentation samples and demonstrates how I approach:

* Technical documentation
* Product and user documentation
* Structured authoring

## What I Document

The portfolio currently features two documentation projects:

### 1. SmartTV — Product & User Documentation

A sample documentation project for a fictional SmartTV streaming application.

**Documentation includes:**

* Product overview
* Getting started
* User workflows
* Feature documentation
* Task-based procedures
* Troubleshooting

**Documentation approach:**

```text
Product Understanding
        ↓
Getting Started
        ↓
Using Features
        ↓
Troubleshooting
```

**Tool:** MadCap Flare
**Output:** HTML5

The project demonstrates topic organization, TOC development, content reuse, variables, cross-references, screenshots, and HTML5 publishing.

---

### 2. AuditX — Structured Technical Documentation

A sample documentation project created to demonstrate **DITA-based structured authoring**.

**Documentation approach:**

* Topic-based authoring
* Concept, Task, and Reference topics
* DITA maps
* Structured content
* Reusable documentation components
* Information architecture

**Tools & technologies:**

* DITA XML
* Oxygen XML Editor
* Markdown
* GitHub

The project demonstrates how technical content can be structured into reusable topics and organized into a documentation hierarchy.

## Design System

The portfolio uses a restrained visual system built around:

| Element          | Value                  |
| ---------------- | ---------------------- |
| Background       | Alabaster `#F3EEE6`    |
| Primary Text     | Midnight Ink `#163F46` |
| Accent           | Deep Maroon `#7F0303`  |
| Secondary Detail | Muted Tan `#C9A982`    |
| Diagram Accent   | Soft Blue `#A9C6D0`    |

The visual language is intentionally editorial and documentation-oriented rather than following a conventional developer portfolio layout.
